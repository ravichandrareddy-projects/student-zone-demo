# student-zone-demo

**Student Zone Xerox & Binding Shop, Tenali** — A modern Next.js web application for online document printing, live order tracking, price estimation, and a local privacy document management vault.

## Features
- **Online Print Ordering**: Upload PDF/images, select color/B&W, paper GSM, sides, and binding options with instant real-time price calculation.
- **Live Swiggy-Style Order Tracker**: Track status from ACCEPTED → PRINTING → FINISHING → READY → COLLECTED.
- **Admin Document Vault & File Privacy**: Direct document downloads with 1-click single file & bulk storage erasure.
- **Kanban Board**: Admin live order management.

## Tech Stack
- Next.js (App Router)
- React, Tailwind CSS, Lucide Icons
- Prisma ORM (SQLite)
